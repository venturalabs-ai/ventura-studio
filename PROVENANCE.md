# Provenance

This file records authorship, governance sources and third-party reference boundaries for `ventura-studio`.

## Ventura-authored material

The ecosystem taxonomy, engineering standard, readiness model, score tooling, profile template and project-governance documentation in this repository are maintained as Ventura Labs AI project material unless a file states otherwise.

## External references

This repository links to Ventura projects and may reference public engineering practices, open-source projects, standards and vendors. References identify sources or context only; they do not imply affiliation, endorsement or certification.

Curated Ventura repositories maintain their own `PROVENANCE.md` files. Third-party license and reuse obligations must be handled in the repository containing the affected material.

## Metrics boundary

`metrics/ecosystem.json` is generated from repository evidence. Static presence checks are not proof that software is correct or production-grade. Production-grade, vulnerability, test and eval claims must only be published when backed by successful automated evidence for the referenced commits/releases.

## Contribution rule

Before adding copied, translated or adapted third-party material, record source/upstream, URL, version/date when practical, license/terms, reuse type and affected files.
