# Ventura Labs AI

**AI Agents · Software Engineering · Security · Automation**

Ventura Labs AI is an engineering ecosystem focused on reusable AI agents, secure automation and reproducible software workflows.

## Flagships

- **[Ventura.SEG](https://github.com/venturalabs-ai/Ventura.SEG)** — security controls for AI-agent systems: permissions, DLP, credential handling, sandboxing and audit.
- **[ventura-pro-agro](https://github.com/venturalabs-ai/ventura-pro-agro)** — FastAPI application for agricultural planning support using climate, ZARC and cost references.
- **[ventura-chat](https://github.com/venturalabs-ai/ventura-chat)** — contextual AI application with memory, RAG and LangGraph orchestration.
- **[autor-ventura](https://github.com/venturalabs-ai/autor-ventura)** — multi-agent editorial pipeline for research, writing and revision.
- **[ventura-agents](https://github.com/venturalabs-ai/ventura-agents)** — reusable business-agent library with contract evals.
- **[ventura-studio](https://github.com/venturalabs-ai/ventura-studio)** — ecosystem governance, maturity model and evidence-based engineering metrics.

## Engineering standard

Flagships are being evolved around verifiable evidence:

`provenance → tests/evals → CI → security → SBOM → SemVer → reproducible releases`

A repository is not described as production-grade solely because it has code, a README or badges.

## Verified metrics

Engineering metrics are generated by the `ventura-studio` Ecosystem Score workflow. Quantitative claims such as production-grade count, test/eval totals or vulnerability counts must only be added here when the corresponding evidence is available for the referenced commits/releases.

Current public positioning: **6 priority flagships with progressive verification**, plus incubating and educational projects clearly classified by maturity.

## Ecosystem

- Core & governance: `ventura-studio`
- Security: `Ventura.SEG`
- Applications: `ventura-pro-agro`, `ventura-chat`
- Agents: `autor-ventura`, `ventura-agents`, `ventura-pro`, `ventura-agents-2`
- Generative media: `ventura-art`, `ai-animation-academy`
- Labs/incubation: vision, voice, data, bio, robotics, social, game and generative-art experiments
- Curated learning: roadmaps, algorithms, system design, APIs, interview preparation and open-source resources

## Principles

- claims must be testable;
- provenance must be explicit;
- third-party licenses and attribution must be respected;
- LLM workflows are not described as deterministic without evidence;
- security controls reduce risk but are not presented as certification;
- metrics must come from automated, reproducible checks whenever practical.
